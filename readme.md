# HugBot
> AI  

HugBot is a vibecoded RC control system for battlebots. With the aim is to be as cheap as possible.

## Setup
### Flashing the RX
1. Set the board to `ESP32C3 dev module`
2. Enable `ACM on boot`
3. upload
4. launch the terminal
5. take note of the MAC addres

### flashing the TX
> Subject to change  

1. Set the board to `ESP32C3 dev module`
2. Enable `ACM on boot`
3. input the MAC addres in sketch
4. upload
